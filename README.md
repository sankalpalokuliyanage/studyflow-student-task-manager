# Studyflow

A responsive student task manager built as a single self-contained HTML file.

## Features

- Create, edit, complete, filter, search, sort, and delete tasks
- Today, upcoming, subject, and progress views
- Weekly progress and priority summaries
- Persistent browser storage
- Responsive desktop and mobile interfaces
- Accessible keyboard focus and reduced-motion support

## Run locally

Open `index.html` directly in a browser. No installation or build step is required.
